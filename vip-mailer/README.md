# 小伐郵件高手（Chrome 外掛）

下載與安裝說明：<https://carminowu-gen1.github.io/picomeeting-assistant/mail/>

從 Excel 或 Google 試算表匯入「稱謂、姓名、Email」，每位收件人各寄一封專屬的信，用自己的 Gmail 寄出。

## 平常怎麼用

1. 點 Chrome 右上角的外掛圖示，會開一個分頁。
2. 把 Excel 檔（.xlsx／.csv）拖進去，或貼上 Google 試算表網址。欄位會自動認出來。
3. 想換寄件人顯示的名稱就填「寄件人名稱」（不填就用 Google 帳號的名稱）；想讓對方回信寄到別的信箱就填「回覆信箱」。寫主旨和內容。要放稱謂、姓名的地方，點一下上面的小按鈕就會插入 `{{稱謂}}`、`{{姓名}}`；Excel 裡其他欄位（例如公司）也會出現按鈕。
   內容框上方有排版工具列（字型、大小、粗斜底線、顏色、對齊、清單、清除格式）。字型／大小／顏色／清除格式：有選取只改選取的，沒選取就整封一起改，貼進來的內容和稱謂姓名才會一致。
4. 「寄件列表」裡每個人前面有打勾，只有打勾的才會寄；最上面那格可以全選／全不選。點某一位，右邊就顯示他實際收到的信；滑鼠移到某一位，右邊的 × 可以把他從列表刪掉（不會動到 Excel）。
   某個人的信要單獨修改：直接點右邊預覽信紙上的主旨或內容改，會自動儲存成他專屬的版本（列表上出現 ✎）。之後再改左邊的範本，改過的人不會跟著變；按「還原」可改回範本。
   Excel 之後又多了人：按列表右上「🔄 名單有更新？重新讀取」（試算表直接重讀，Excel 檔再選一次）。用 Email 對照，新人加在最後；原本的人保留寄過／沒寄、打勾、個別修改（個別修改過的人整列不動）；已寄過但新名單裡沒有的人留在最後當紀錄。
   稱謂要自動換字（教授、副教授 → 老師）：列表下方「稱謂自動轉換」按「修改」，左邊填名單裡的字（用「、」隔開），右邊填要改成的字。預設有一條「教授、副教授、助理教授 → 老師」，可以改或刪；規則結案後仍會保留。
5. 想知道對方有沒有收到，勾「請對方確認收到」：信末會多一顆「我已收到」按鈕，對方點了會開啟一封寫好的回覆信，按傳送你就會收到。
6. 「先寄一封給自己看看」確認沒問題，再按「寄出勾選的 N 封」。

按「✓ 暫存／結案，開新案件」可以把這一案收進右上角的「案件紀錄」（取名字、填會議日期，列表會顯示日期也能搜尋）：「暫存」是還要再寄，之後從案件紀錄按「打開這個案件」就原樣回來接著寄，可以同時放好幾個案子；「結案」是寄完歸檔（需要時也能重新打開補寄，寄過的不會重寄）。打開另一案時畫面上那一案會自動暫存。案件紀錄可回查寄給了誰、何時寄、每個人收到的內容，也能搜尋或沿用舊信的內容；列表上每筆可改名字／日期、刪除，勾選後可批次刪除。案件紀錄只存在這台電腦的 Chrome 裡，移除外掛就會消失。

名單和信件內容會自動記住，關掉再開還在。寄到一半中斷，再開會從沒寄的接著寄，不會重複寄。附件不會記住，重開要再加一次。

名單格式：第一列是標題（稱謂／姓名／Email，順序不拘，也認得 Title、Name、信箱、職稱等寫法），之後一列一位。

## 第一次設定（只做一次，約 10 分鐘）

寄信走 Google 官方的 Gmail API，所以要先申請一組自己的用戶端 ID。授權大約一小時會過期，過期時外掛會自動續，偶爾會再跳一次選帳號的視窗。

1. **載入外掛**：Chrome 開 `chrome://extensions` → 右上角開「開發人員模式」→「載入未封裝項目」→ 選這個 `vip-mailer` 資料夾。
   外掛 ID 會固定是 `hgldmebiafknndoekhfaiggbcfecpfic`。
2. **建 Google 專案**：到 <https://console.cloud.google.com/> 建一個專案（也可以沿用現有的）。
3. **啟用 API**：「API 和服務」→「程式庫」，搜尋並啟用 **Gmail API** 和 **Google Sheets API**。
4. **同意畫面**：「OAuth 同意畫面」→ 使用者類型選「外部」→ 維持「測試中」→ 在「測試使用者」加入要寄信的 Gmail 帳號。
5. **建立憑證**：「憑證」→「建立憑證」→「OAuth 用戶端 ID」→ 應用程式類型選 **網頁應用程式** → 在「已授權的重新導向 URI」貼上外掛設定畫面顯示的那一串（`https://hgldmebiafknndoekhfaiggbcfecpfic.chromiumapp.org/`，畫面上有「複製」按鈕）→ 建立，複製用戶端 ID（`xxxx.apps.googleusercontent.com`）。
6. **貼進外掛**：點外掛圖示，第一次會自動出現設定畫面。把用戶端 ID 貼進去，按「連結 Google 帳號」，在跳出的視窗選要用來寄信的帳號。完成後設定畫面會自己收起來。

不用改任何檔案。之後想換帳號或換用戶端 ID，點右上角的「寄件帳號」就會再出現設定畫面。

連結帳號時 Google 可能顯示「Google 尚未驗證這個應用程式」，點「進階」→「繼續」即可（這是你自己的應用程式）。

## 新版本提醒與發布

打開外掛時會自動檢查有沒有新版（最多每 10 分鐘查一次）。有新版時畫面上方會出現「🎁 有新版本」，點「下載新版」拿到 zip，解壓縮蓋掉原本的資料夾，再到 `chrome://extensions` 按外掛的重新整理。Chrome 不允許手動載入的外掛自己覆蓋檔案，所以最後這一步要手動；上架 Chrome 線上應用程式商店後才會完全自動更新。

發布新版的方法（開發者）：

1. 改 `vip-mailer/manifest.json` 的 `version`（例如 `1.2.1`），提交並推上 GitHub。
2. 推一個同版號的標籤：`git tag mail-v1.2.1`，再 `git push origin mail-v1.2.1`。
3. GitHub Actions（`.github/workflows/release-mail.yml`）會自動打包成 `xiaofa-mail.zip` 並建立 Release。

## 要知道的限制

- 收信確認要對方自己點按鈕並送出回覆才算數，外掛沒辦法偷偷知道對方開信了沒。同時也會送出「讀取回條」請求，但 Gmail 個人帳號多半不理會，Outlook 等會跳出詢問。
- Gmail 每天寄信上限：一般帳號約 500 封，Google Workspace 約 2000 封。
- 寄件帳號是連結時選的那個 Google 帳號，寄出的信會出現在 Gmail 的「寄件備份」。
- 舊版 `.xls` 不支援，請另存成 `.xlsx`。放在雲端硬碟的 Excel 檔（不是 Google 試算表）要下載後拖進來。
- 附件合計上限 20 MB。
