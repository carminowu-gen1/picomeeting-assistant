小伐郵件高手

Excel 名單拖進來，每個人收到一封寫著自己稱謂和姓名的專屬信。

下載小伐郵件高手
Chrome 外掛 · 免費 · 用自己的 Gmail 寄出

可以做什麼

  • 匯入 Excel、CSV 或 Google 試算表
  • 自動帶入每個人的稱謂、姓名
  • 寄出前逐封預覽實際內容
  • 打勾才寄，可單獨刪除某一位
  • 自訂寄件人名稱與回覆信箱
  • 信末「我已收到」確認按鈕
  • 每人單獨收信，看不到其他人
  • 中斷後接著寄，不會重複

安裝（約 1 分鐘）

  1. 按上面的按鈕下載 xiaofa-mail.zip，在檔案上按右鍵 →「解壓縮全部」。解出來的資料夾請放在不會被移動或刪掉的地方（例如「文件」）。
  2. 在 Chrome 網址列輸入 chrome://extensions 按 Enter。
  3. 打開頁面右上角的「開發人員模式」。
  4. 點左上角的「載入未封裝項目」，選剛剛解壓縮的資料夾。
  5. 點 Chrome 右上角的拼圖圖示 🧩，在「小伐郵件高手」旁邊按圖釘，之後點圖示就能開啟。

第一次設定 Google 授權（約 10 分鐘，只做一次）

  1. 到 Google Cloud Console 建一個專案。
  2. 「API 和服務」→「程式庫」，啟用 Gmail API 和 Google Sheets API。
  3. 「OAuth 同意畫面」→ 使用者類型選「外部」→ 維持「測試中」→ 在「測試使用者」加入要寄信的 Gmail。
  4. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」→ 類型選「網頁應用程式」。在「已授權的重新導向 URI」貼上外掛設定畫面顯示的那一串（有「複製」按鈕）。「已授權的 JavaScript 來源」留空。
  5. 把拿到的「用戶端 ID」貼回外掛，按「連結 Google 帳號」，選要寄信的帳號。用戶端密碼不需要。

連結時若顯示「Google 尚未驗證這個應用程式」，點「進階」→「繼續」即可，這是你自己建立的應用程式。同一組用戶端 ID 可以給家人用，記得先把對方的 Gmail 加進「測試使用者」。

新版本來敲門了 🎁

  1. 外掛畫面上方出現「🎁 有新版本」時，點「下載新版」（或回到這一頁按下載）。
  2. 解壓縮到原本的資料夾，問要不要取代時選「取代目的地中的檔案」。
  3. 到 chrome://extensions，按小伐郵件高手卡片上的重新整理（圓形箭頭）。

名單、信件內容和授權設定都會保留。
