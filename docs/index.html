為什麼做這個？💛

這個小工具，是為了我老婆做的。她在公司常常要開線上會議，一邊聽一邊抄筆記，總是抄不完，也聽不完整。所以我做了它：開會時按一下，它就把大家說的話記下來；散會後，自動整理成摘要和待辦事項。支援 Google Meet、Teams、Zoom 這些網頁會議；實體會議就把手機放在桌上，它會自動分辨是誰在說話。沒有複雜的設定，也沒有用不到的功能，就算完全不懂電腦，也能輕鬆上手。

常見問題

Teams、Zoom 也能用嗎？

可以！Google Meet、Teams、Zoom、Jitsi 都行，不過要用網頁版，也就是在 Chrome 裡開會。電腦上安裝的 Teams／Zoom 應用程式，它聽不到。

背景音樂、冷氣聲會不會被記進去？

不會。降噪（RNNoise）和語音偵測（Silero VAD）都在你的電腦或手機上先跑一遍，只有真的有人在說話的片段才會送去辨識，所以不會出現「音樂被翻成歌詞」這種事。

載入時出現「Cannot load extension… desktop.ini」？

這是選錯資料夾，或 Windows 在資料夾裡放了隱藏檔 desktop.ini。在「文件」裡新建一個空資料夾，把 zip 解壓縮到裡面，載入時選打開就看得到 manifest.json 的那一層（不要選「下載」或「桌面」）。還是不行的話：檔案總管上方「檢視 → 顯示 → 隱藏的項目」，把那個資料夾裡的 desktop.ini 刪掉再載入一次。

電腦比較慢（例如 Surface Go）怎麼辦？

最吃效能的其實是會議本身。試試這幾招：① 在 Meet／Teams 裡關掉背景模糊、虛擬背景和視訊特效（最有感）；② 不需要看畫面時關掉自己的視訊；③ 會議中不用一直開著「查看全文」，會後再看就好；④ 開會時關掉其他不用的分頁；⑤ 筆電插著電源，Windows 電源模式選「最佳效能」。

Mac 錄不到我的聲音？

多半是 macOS 還沒把麥克風交給 Chrome。打開「系統設定 → 隱私權與安全性 → 麥克風」，把 Google Chrome 的開關打開，再回 Chrome 重新按「開始記錄」。第一次錄音時如果跳出「Chrome 想要使用麥克風」，記得按「允許」。

逐字稿怎麼一直沒出現？

先看 ✦ 裡的兩條綠色音量條：「我」不跳 → 到設定頁按「測試麥克風」；「對方」不跳 → 會議本身沒有聲音。另外，說完話大約 3～15 秒文字才會出現，給它一點時間 ⏳

手機版上的 🎤 和 ✦ 小燈是什麼？

🎤 是麥克風、✦ 是 Groq 連線的狀態燈。綠燈代表一切正常；紅燈閃爍代表有問題，點一下它就會用白話告訴你怎麼修（例如麥克風沒允許、金鑰貼錯）。

手機版怎麼知道是誰在說話？會認錯嗎？

它靠聲紋（每個人聲音的特徵）分辨，全部在手機上完成、不花錢也不上傳。一開始會標成「說話者 A、B、C」，點一下就能改名；打一個已經有的名字，兩個標籤就會合併。它不太確定時會用虛線標籤加「?」提醒你，確定時是實線。聲音很像的人偶爾會認錯，改一下名字就好。

英文、中英夾雜也行嗎？

行！中文、英文、日文、中英夾雜，它都會照原文記錄，不會擅自翻譯；簡體中文會自動轉成繁體。

會議內容安全嗎？

逐字稿和摘要只存在你自己的電腦或手機裡。降噪和語音偵測都在本機完成；辨識時，只有有人在說話的聲音片段會加密傳給 AI 處理。詳見隱私權政策。

要先告訴其他人嗎？

要喔！開始記錄前，先跟大家說一聲「這場會議會記錄」。這是基本禮貌，很多地方也是法律要求。
