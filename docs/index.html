會議摘要助理

開會時自動記下每個人說的話，會後用 AI 整理成摘要、重點和待辦事項，一鍵下載 Word。支援 Google Meet、Teams、Zoom、Jitsi。

⬇ 下載並安裝 免費・約 2 分鐘裝好

怎麼用？

1
進入會議

用 Chrome 打開 Google Meet、Teams 或 Zoom 的會議。

2
按「開始記錄」

點右上角的 ✦ 圖示，按大大的藍色按鈕。

3
開完會直接離開

摘要會自動產生，按「Word」就能下載。

安裝

  1. 打開商店頁面

    按上面的「加到 Chrome」按鈕。

  2. 按「加到 Chrome」→「新增擴充功能」
  3. 照著跳出的設定頁做

    允許麥克風、把圖示釘在工具列，大約 1 分鐘。

安裝（手動，只要做一次）

  1. 下載安裝檔

    ⬇ 下載 meeting-assistant.zip

  2. 解壓縮到一個不會刪掉的地方

    在下載的檔案上按右鍵 →「解壓縮全部」，位置選「文件」資料夾。
    ⚠️ 之後不要刪掉或搬動這個資料夾，否則擴充功能會失效。

  3. 打開 Chrome 的擴充功能頁

    按下面的按鈕複製網址，貼到 Chrome 的網址列，按 Enter。

    chrome://extensions
  4. 打開右上角的「開發人員模式」

    把開關切到藍色。

  5. 按左上角「載入未封裝項目」

    選剛剛解壓縮出來的資料夾（裡面要看得到 manifest.json 這個檔案），按「選擇資料夾」。

  6. 照著跳出的設定頁做

    允許麥克風、貼上金鑰（頁面上有教學）、把圖示釘在工具列。

Chrome 可能會提醒「停用開發人員模式擴充功能」，請選保留，不然就要重新安裝。

有新版本時怎麼更新

出現「有新版本」的提醒時：

  1. 下載新的安裝檔

    按上面同一個下載按鈕。

  2. 解壓縮，覆蓋原本的資料夾

    解壓縮到同一個位置，問到要不要取代檔案時選「取代」。

  3. 到 chrome://extensions 按「會議摘要助理」上的 ↻ 重新載入

    會議記錄和設定都會保留。

常見問題

Teams、Zoom 可以用嗎？

可以，但要用網頁版開會（在 Chrome 裡開），電腦上安裝的 Teams／Zoom 應用程式不行。

逐字稿一直沒有出現？

看一下圖示裡的兩條綠色音量條：「我」不會跳，請到設定頁按「測試麥克風」；「對方」不會跳，代表會議沒有聲音。說話後大約 3～15 秒文字才會出現。

可以記錄英文或中英夾雜嗎？

可以，會照原文記錄，不會自動翻譯。簡體中文會自動轉成繁體。

會議內容存在哪裡？安全嗎？

逐字稿和摘要只存在你自己的電腦裡；辨識時聲音會加密傳給 AI 服務處理。詳見隱私權政策。

需要先告知其他人嗎？

需要。開始記錄前，請先告訴與會者這場會議會被記錄。
