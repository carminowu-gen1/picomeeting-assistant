為什麼做這個？💛

這個小工具，是為了我老婆做的。她在公司常常要開線上會議，一邊聽一邊抄筆記，總是抄不完，也聽不完整。所以我做了它：開會時按一下，它就把大家說的話記下來；散會後，自動整理成摘要和待辦事項。支援 Google Meet、Teams、Zoom 這些網頁會議。沒有複雜的設定，也沒有用不到的功能，就算完全不懂電腦，也能輕鬆上手。

常見問題

Teams、Zoom 也能用嗎？

可以！不過要用網頁版，也就是在 Chrome 裡開會。電腦上安裝的 Teams／Zoom 應用程式，它聽不到。

載入時出現「Cannot load extension… desktop.ini」？

這是選錯資料夾，或 Windows 在資料夾裡放了隱藏檔 desktop.ini。在「文件」裡新建一個空資料夾，把 zip 解壓縮到裡面，載入時選打開就看得到 manifest.json 的那一層（不要選「下載」或「桌面」）。還是不行的話：檔案總管上方「檢視 → 顯示 → 隱藏的項目」，把那個資料夾裡的 desktop.ini 刪掉再載入一次。

電腦比較慢（例如 Surface Go）怎麼辦？

最吃效能的其實是會議本身。試試這幾招：① 在 Meet／Teams 裡關掉背景模糊、虛擬背景和視訊特效（最有感）；② 不需要看畫面時關掉自己的視訊；③ 會議中不用一直開著「查看全文」，會後再看就好；④ 開會時關掉其他不用的分頁；⑤ 筆電插著電源，Windows 電源模式選「最佳效能」。

Mac 錄不到我的聲音？

多半是 macOS 還沒把麥克風交給 Chrome。打開「系統設定 → 隱私權與安全性 → 麥克風」，把 Google Chrome 的開關打開，再回 Chrome 重新按「開始記錄」。第一次錄音時如果跳出「Chrome 想要使用麥克風」，記得按「允許」。

逐字稿怎麼一直沒出現？

先看 ✦ 裡的兩條綠色音量條：「我」不跳 → 到設定頁按「測試麥克風」；「對方」不跳 → 會議本身沒有聲音。另外，說完話大約 3～15 秒文字才會出現，給它一點時間 ⏳

英文、中英夾雜也行嗎？

行！它會照原文記錄，不會擅自翻譯；簡體中文會自動轉成繁體。

會議內容安全嗎？

逐字稿和摘要只存在你自己的電腦裡。辨識時，聲音會加密傳給 AI 處理。詳見隱私權政策。

要先告訴其他人嗎？

要喔！開始記錄前，先跟大家說一聲「這場會議會記錄」。這是基本禮貌，很多地方也是法律要求。
