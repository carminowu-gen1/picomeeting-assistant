把小伐速記放到手機桌面

放到桌面後，就像一般 App 一樣一點就開，設定也只要做一次。

你現在是在 LINE／Facebook 裡面開的，這裡沒辦法放到桌面。請按右上角（或右下角）的選單，選「用 Safari 開啟」或「用瀏覽器開啟」。

  1. 1按 Safari 最下面的「分享」按鈕
    新版 iPhone：先按右下角「⋯」，再按「分享」
  2. 2往下滑，點「加入主畫面」
  3. 3按右上角「新增」。桌面出現小伐的圖示後，從圖示打開繼續設定

按右上角「⋮」→「加到主畫面」或「安裝應用程式」

✓ 裝好了！請關掉這頁，從手機桌面的「小伐速記」圖示打開

小伐速記

會議摘要助理

把手機放在桌上，它會記下每個人說的話，
散會後自動整理成摘要。

1

先把它放到手機桌面

iPhone 會把「桌面的 App」和「Safari」分開存資料，先放到桌面、再從桌面打開設定，金鑰就只要貼一次。

  1. 按 Safari 下面的「分享」⎙
  2. 往下找「加入主畫面」→ 右上角「新增」
  3. 關掉 Safari，從桌面的「會議摘要」圖示打開，繼續下面的步驟

已經是從桌面打開的，就不會看到這一步。

1

允許使用麥克風

按下按鈕，手機會問你要不要允許，請按「允許」，然後隨便說幾句話。

2

連接 AI（免費）

辨識和摘要用 Groq 的免費服務，需要一組「金鑰」，三步拿到：

  1. 打開 Groq 網站 ↗，用 Google 帳號登入
  2. 按「Create API Key」→ 名稱隨便填 → 「Submit」
  3. 按「Copy」，回到這裡貼上

金鑰只存在這支手機裡，只會在辨識時直接送給 Groq。

下一步會教你把它放到手機桌面，以後就像 App 一樣一點就開。
