會議摘要助理

把手機放在桌上，它會記下每個人說的話，
散會後自動整理成摘要。

1

先把它放到手機桌面

iPhone 會把「桌面的 App」和「Safari」分開存資料，先放到桌面、再從桌面打開設定，金鑰就只要貼一次。

  1. 按 Safari 下面的「分享」⎙
  2. 往下找「加入主畫面」→ 右上角「新增」
  3. 關掉 Safari，從桌面的「會議摘要」圖示打開，繼續下面的步驟

已經是從桌面打開的，就不會看到這一步。

1

允許使用麥克風

按下按鈕，手機會問你要不要允許，請按「允許」，然後隨便說幾句話。

2

連接 AI（免費）

辨識和摘要用 Groq 的免費服務，需要一組「金鑰」，三步拿到：

  1. 打開 Groq 網站 ↗，用 Google 帳號登入
  2. 按「Create API Key」→ 名稱隨便填 → 「Submit」
  3. 按「Copy」，回到這裡貼上

金鑰只存在這支手機裡，只會在辨識時直接送給 Groq。

下一步會教你把它放到手機桌面，以後就像 App 一樣一點就開。
